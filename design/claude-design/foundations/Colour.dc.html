TailorMyResume foundations · 02

Colour

Every role in light and dark, its Material 3 slot, and measured WCAG contrast. Text pairs pass 4.5:1; UI lines pass 3:1. Values are computed from the hex codes shown.

Status never relies on colour

met, partial and gap each pair a distinct shape with a word. In greyscale the three still read apart.

gap is a to-do, not an alarm

Calm slate in both themes. It never shares a hue with error. The word is “To prepare”.

error is rare

Only for real failures (upload failed, export failed) and destructive actions (delete). Never for a missing skill.

special is reserved

Marigold, far from jade on the wheel. It appears on the pack purchase button and nowhere else; the character’s shirt shares the hue but is illustration, not UI.

Dark layers

Ground #0E1013 → sheet #15181C → card #1E2228 → document #1C2127 with border → tool #2B313A with border and deep shadow. Each step is a visible lightness jump, so no blur is needed.

Outline button border

outlineSoft (1.42:1 light) is decorative: the label meets 4.5:1 and the 48 dp pill shape identifies the control. Focus uses a 2 dp primary ring (5.31:1).
