TailorMyResume foundations · 05

Motion

Two named registers. proof is the default: crisp, low overshoot, it never draws attention. hop is springy and reserved for progress moments. All values are Compose spring() specs.

motion.proof

Default for everything: navigation, sheets, lists, reveals, diffs, source links, waiting.

object Proof {
  val spatial = spring<Float>(dampingRatio = 0.9f, stiffness = 600f)
  val spatialFast = spring<Float>(dampingRatio = 1f, stiffness = 1400f)
  val offset = spring<IntOffset>(0.9f, 600f, IntOffset.VisibilityThreshold)
  val fade = tween<Float>(150, easing = LinearOutSlowInEasing)
  const val STAGGER_MS = 30; const val STAGGER_MAX = 6
}

dampingRatio 0.9 · stiffness 600 · settles ≈ 280 ms · overshoot < 1%

motion.hop

Progress moments only. Never on navigation, errors, or anything the user must read.

object Hop {
  val spatial = spring<Float>(dampingRatio = 0.55f, stiffness = 380f)
  val scale = spring<Float>(dampingRatio = 0.5f, stiffness = 500f)
  // used only for: gap closed, application exported,
  // pack purchased, first fact confirmed
}

dampingRatio 0.55 · stiffness 380 · settles ≈ 520 ms · overshoot ≈ 12%

Sequences

Three frames each: start, middle, settled.

Sheet riseproof

Sheet translates 48 dp → 0 and fades 0 → 1 over the header on screen entry. Header stays still.

Reduced: Sheet appears in place, no translate.

List enterproof

Cards rise 12 dp and fade in, 30 ms stagger, first 6 only; the rest appear with the 6th.

Reduced: All cards appear at once.

Gap-analysis revealproof

Rows reveal in JD order, 40 ms apart. Each mark draws in (scale 0.8 → 1). The fraction and segments fill as rows land, so “9 / 14” is the true count at every frame.

Reduced: Final list and fraction render at once.

Bullet diffproof

Original dims to onSurfaceVariant. Rewritten line fades in below. Evidence fill wipes left → right per changed word (120 ms each), then the 2 dp underline draws.

Reduced: Both lines and highlights static.

Source-link revealproof

Tap a line: the fact card expands under it (height spring) and a 2 dp connector draws from line to card. The fact ID tints once.

Reduced: Card shown expanded, no connector draw.

Honest waitingproof

Named steps tick in order with real counts (“Checking 23 facts”). Active step shows a 90° arc rotating at 1 turn / 1.2 s. No percentage, no fake bar. After 20 s add “Still working, this one is long.”

Reduced: Arc replaced by a static ring; step text still updates.

Gap closedhop

Dashed circle morphs to filled check: scale 0.8 → 1 with overshoot, segment in the bar fills, fraction ticks 9 → 10.

Reduced: Mark swaps instantly; fraction updates.

Exportedhop

Export-done character lifts 12 dp and settles; resume card scales 0.96 → 1. Snackbar enters with proof.

Reduced: Static illustration; snackbar appears.

“Remove animations” fallback

Read Settings.Global.ANIMATOR_DURATION_SCALE once per resume. When it is 0, provide LocalMotion = Motion.Reduced: every spring becomes snap(), staggers become 0, the waiting arc becomes a static ring. Content order and step text still change, so progress stays readable. Fades of 150 ms or less may stay, they carry no movement.

val reduced = Settings.Global.getFloat(
  resolver, ANIMATOR_DURATION_SCALE, 1f) == 0f
val motion = if (reduced) Motion.Reduced else Motion.Default
CompositionLocalProvider(LocalMotion provides motion) { App() }

// Motion.Reduced
spatial = snap(); stagger = 0; arc = Static

60 fps on a 3 GB phone

Animate graphicsLayer (translationY, alpha, scale) only, never size or padding in a LazyColumn. One stagger chain at a time. No blur, no RenderEffect, no animated shadows: shadows are fixed per elevation step. Springs are interruptible, so a tap mid-motion never waits.
