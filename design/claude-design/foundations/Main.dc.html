Rupee sign ₹ (U+20B9) — confirmed in both

Checked in the font files: Plus Jakarta Sans and IBM Plex Mono both carry U+20B9 in their latin-ext subset, not in basic latin. Bundle the full TTF in res/font, or include latin-ext if you subset. Digits use the tnum feature; ₹ is a prefix, so its width does not shift columns.

Devanagari fallback — Noto Sans Devanagari

नमस्ते, प्रिया · 9 / 14 मुख्य शब्द

Already on Android as a system font, so no extra download on a 3 GB phone. Variable 100–900, so it maps 1:1 to 400 / 600 / 700 / 800. Its upright, open forms sit well beside Jakarta’s geometric Latin. For Hindi, add +4 sp line height on body and label styles for matras and conjuncts. Alternative if a bundled face is wanted: Mukta.
